# WirelessMathBench Homepage

This repository contains the source code for the WirelessMathBench project homepage. The website showcases our research paper "WirelessMathBench: A Mathematical Modeling Benchmark for LLMs in Wireless Communications" and provides information about the benchmark, results, and team.

## Contents

- `index.html`: Main homepage content
- `styles.css`: CSS styling for the website
- Image placeholders for required graphics

## Setup Instructions

### Local Development

To view the website locally:

1. Clone this repository
2. Open `index.html` in your web browser

### Deploying to a Server

To deploy this website to a web server:

1. Replace the image placeholders (`.placeholder` files) with actual images
2. Update links in the HTML to point to your actual paper, code repository, and dataset
3. Upload all files to your web server

### Required Images

Before deploying, you need to replace these placeholder files with actual images:

- `teaser.png`: Main teaser image showing example tasks from the benchmark
- `wordcloud.png`: Word cloud visualization of topics covered in the benchmark
- `error_distribution.png`: Pie chart showing the error analysis results

### Customizing Links

Update these links in the `index.html` file:

- Paper link: Update the arXiv link once your paper is published
- Code repository: Update with your actual GitHub repository URL
- Dataset link: Update with your Hugging Face or other dataset hosting URL
